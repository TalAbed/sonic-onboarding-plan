# Exercise 1: Variables, Types, and Input

## Overview

This is your first hands-on Python exercise. You'll practice creating variables, understanding data types, converting between types, and using formatted output. These fundamentals are essential for every Python program you'll write.

---

## Learning Objectives

By the end of this exercise, you will be able to:

✅ Create variables with meaningful names  
✅ Understand Python's core data types (string, int, float, bool)  
✅ Use the `input()` function to read user input  
✅ Convert between data types using `int()`, `float()`, `str()`  
✅ Use f-strings to format and print output  
✅ Perform basic arithmetic with variables  

---

## What You'll Practice

| Concept | Used For |
|---------|----------|
| Variable assignment | Storing data |
| Naming conventions | Writing readable code |
| `input()` function | Reading user input |
| `int()`, `float()`, `str()` | Type conversion |
| Arithmetic operators | Computing values |
| f-strings | Formatted output |
| `print()` | Displaying results |

---

## The Scenario

Imagine you're building a simple system to capture employee information. You need to:

1. Ask the user for their name (text)
2. Ask for their age (number)
3. Ask for their monthly salary (decimal number)
4. Store these properly typed values
5. Display a formatted summary
6. Calculate their annual salary

This is a realistic pattern you'll use constantly in data pipelines: **read input → validate types → compute → display output**.
